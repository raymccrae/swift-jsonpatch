# Repository workflow

- Reserve `master` for released versions.
- Use `develop` as the current development head.
- Create `feature/<topic>` branches from `develop` for proposed work.
- Keep proposed work on its feature branch until it is selected for merging into `develop`.
- Update `master` as part of a release.

## Superpowers

Superpowers skills are opt-in. Do not automatically invoke them based on task matching, and do not invoke `using-superpowers` unless the user explicitly requests Superpowers. Otherwise, use normal Codex behavior.
